Lecture 05: CSS Selection

Overview

CSS selectors are used to select the HTML elements you want to style. They allow you to apply rules to specific elements, groups of elements, or unique elements.

Common Types of Selectors

  • Element Selector: Selects elements based on element name (e.g., p, h1).
  • Class Selector: Selects elements with a specific class using a dot (e.g., .highlight).
  • ID Selector: Selects a single element with a specific ID using a hash (e.g., #header).
  • Grouping Selector: Selects multiple elements separated by commas (e.g., h1, h2, p).

Sample Program

Program demonstrating element, class, and ID selectors:

HTML & CSS Code
<style>
    p {
        color: #334155;
        font-size: 14px;
    }

    .class-sample {
        color: #b91c1c;
        background-color: #fee2e2;
        padding: 4px 8px;
        border-radius: 4px;
        font-weight: bold;
    }

    #id-sample {
        color: #047857;
        background-color: #d1fae5;
        padding: 4px 8px;
        border-radius: 4px;
        font-weight: bold;
    }
</style>

<p>This is styled by an element selector.</p>
<span class="class-sample">Styled with Class Selector (.class-sample)</span><br><br>
<span id="id-sample">Styled with ID Selector (#id-sample)</span>
