Lecture 07: Responsive Web Design

Overview

Responsive Web Design (RWD) makes web pages look good and work well on all devices, including desktops, laptops, tablets, and mobile phones.

Key Concepts

  • Viewport Tag: <meta name="viewport" content="width=device-width, initial-scale=1.0"> sets the page width to fit device screens.
  • Media Queries: @media rules apply CSS styles only when specific screen dimensions are met.
  • Flexible Layouts: Using relative units like percentages (%) and Flexbox (display: flex) rather than fixed pixel widths.

Sample Program

A simple responsive column layout using media queries and Flexbox:

HTML & CSS Code
<style>
    .row {
        display: flex;
        flex-wrap: wrap;
        gap: 12px;
    }

    .column {
        flex: 1 1 calc(33.333% - 12px);
        background-color: #f1f5f9;
        border: 1px solid #cbd5e1;
        padding: 15px;
        text-align: center;
        min-width: 160px;
    }

    @media screen and (max-width: 600px) {
        .column {
            flex: 1 1 100%;
        }
    }
</style>

<div class="row">
    <div class="column">Column 1</div>
    <div class="column">Column 2</div>
    <div class="column">Column 3</div>
</div>
