Lecture 06: CSS Box Model and Layout

Overview

In CSS, every HTML element is considered a rectangular box. The CSS Box Model describes how the content, padding, border, and margin work together to determine the element's total space on the screen.

The Four Parts of the Box Model

  • Content: The actual text or image inside the box.
  • Padding: Transparent space between the content and the border.
  • Border: A line that goes around the padding and content.
  • Margin: Transparent space outside the border, creating space between different elements.

Sample Program

Applying the Box Model to an element:

HTML & CSS Code
<style>
    .box-demo {
        width: 250px;
        padding: 20px;
        border: 4px solid #173b63;
        margin: 15px 0;
        background-color: #93c5fd;
        text-align: center;
        font-weight: bold;
    }
</style>

<div class="box-demo">
    Box Model Element
</div>

Output

Output
Box Model Element

This box has 250px width, 20px padding, 4px solid border, and 15px margin.
