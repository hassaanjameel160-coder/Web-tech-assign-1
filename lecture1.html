Lecture 01: Introduction to Web Technologies

Overview

Web Technologies are the tools and languages used to create and display websites on the Internet. Websites work on a client-server model where a web browser requests web pages from a server.

Core Technologies

  • HTML: Defines the structure and content of the webpage.
  • CSS: Handles styling, colors, and layout.
  • JavaScript: Adds interactivity and functionality to the page.

Sample Program

A basic HTML document structure:

HTML Code
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>My First Page</title>
</head>
<body>
    <h1>Introduction to Web Technologies</h1>
    <p>Welcome to Web Technologies course.</p>
    <p>HTML provides the basic skeleton for web pages.</p>
</body>
</html>
