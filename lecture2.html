Lecture 02: HTML Basics

Overview

HTML (HyperText Markup Language) uses tags to structure text, headings, lists, links, and media elements on a web page.

Topics Covered

  • Headings: <h1> to <h6> define heading hierarchy.
  • Paragraphs: <p> creates blocks of text.
  • Text Formatting: <b> (bold), <i> (italic), <mark> (highlighted text).
  • Lists: <ul> for bulleted lists and <ol> for numbered lists.
  • Links: <a href="..."> creates clickable hyperlinks.

Sample Program

A sample program demonstrating basic HTML elements:

HTML Code
<h2>HTML Basics Example</h2>
<p>
    HTML is <b>easy to learn</b> and <i>essential</i> for web development.
</p>

<h3>My Topics:</h3>
<ul>
    <li>Headings and Paragraphs</li>
    <li>Ordered and Unordered Lists</li>
    <li>Hyperlinks</li>
</ul>

<p>
    Visit: <a href="https://www.google.com" target="_blank">Google Search</a>
</p>
