Lecture 04: Introduction to CSS

Overview

CSS (Cascading Style Sheets) is used to style and format HTML pages. It allows developers to control colors, typography, borders, and layouts.

How to Apply CSS

  • Inline CSS: Using the style attribute directly in an HTML tag.
  • Internal CSS: Inside a <style> tag within the <head> section.
  • External CSS: Linked from a separate .css file using <link rel="stylesheet" href="style.css">.

Sample Program

Example of styling a card box using CSS:

HTML & CSS Code
<style>
    .card-box {
        background-color: #e0f2fe;
        border: 2px solid #0284c7;
        border-radius: 6px;
        padding: 15px;
        text-align: center;
        max-width: 400px;
    }

    .card-box h3 {
        color: #0369a1;
        margin-bottom: 6px;
    }

    .card-box p {
        color: #334155;
        font-size: 14px;
    }
</style>

<div class="card-box">
    <h3>CSS Styling Demo</h3>
    <p>This box is styled using CSS properties.</p>
</div>
